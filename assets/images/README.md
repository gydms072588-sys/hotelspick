## 영역 연결

- 히어로 3장: hero-01 (국내 제주), hero-02 (몰디브 휴양지), hero-03 (프리미엄 호텔). 기존 label span 내부의 img에 object-fit: cover 적용.
- 특가 호텔 6개: hotel-01 ~ hotel-06, 각 카드마다 서로 다른 사진.
- 평점 높은 숙소 8개: hotel-01 ~ hotel-08. 모든 국내·해외 카테고리에 8개를 재사용하며 한 그리드 내 중복 없음.
- HOT 여행지: destination-{지역명}을 해당 지역 썸네일과 프로모션 4개에 공유. 기존 4개 슬라이드·타이머·닷 기능 보존.
- 제휴 배너: partner-01. 기존 글자색을 유지하면서 배경에 밝은 그라디언트를 적용해 가독성을 확보.

모든 경로는 assets/images 기준 상대경로이며 실행 중 외부 이미지 요청은 없습니다. 히어로 1920px, 호텔 900px, 여행지 1200px, 제휴 1600px로 축소한 뒤 WebP 품질 78로 최적화했습니다.
