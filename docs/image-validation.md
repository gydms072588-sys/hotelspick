# 이미지 적용 검증

> 아래는 최초 사진 적용 검증 기록입니다. 상단 배너의 후속 일러스트 교체는 [배너 변경 문서](banner-update.md)에 기록했습니다.

확인일: 2026-10-13. 로컬 HTTP 서버와 Chromium에서 확인했습니다.

## 확인 결과

- 18개 WebP 파일 모두 디코딩 성공. 총 2,787,212 bytes (약 2.66 MiB).
- 초기 화면의 모든 이미지와 CSS 배경 로딩 성공. 전체 파일 경로 및 디코딩도 별도 확인.
- 히어로 3개 선택 및 활성 표시, 국내·해외 여행지 6개 선택과 각 프로모션 4개 선택 정상.
- 평점 높은 숙소 국내·해외의 모든 카테고리에서 각 8개 이미지 연결 확인.
- JavaScript 구문 검사 통과, 브라우저 JavaScript 오류 없음.
- `index.html` 변경 없음. CSS는 이미지 관련 규칙만 추가. 기존 타이머·캐러셀·검색·탭 이벤트 구현 유지.
- 히어로는 `object-fit: cover`, 기존 카드·지역·제휴 배경은 `background-size: cover`로 비율을 유지하며 채움.

## PC·모바일 비교

브라우저 뷰포트: PC 1440 × 1000, 모바일 390 × 844. 스크롤바를 제외한 실제 콘텐츠 폭은 각각 1425px, 375px입니다. 아래 크기는 적용 전후 동일했습니다.

| 요소 | PC 너비 × 높이 | 모바일 너비 × 높이 |
| --- | --- | --- |
| 헤더 | 1425 × 50 | 375 × 50 |
| 히어로 | 1425 × 580 | 375 × 560 |
| 검색창 | 1120 × 148 | 335 × 218 |
| 특가 카드 | 312 × 510 | 92.98 × 510 |
| 여행지 프로모션 | 576 × 370 | 190 × 370 |
| 평점 숙소 이미지 | 231.5 × 308.66 | 67.25 × 89.66 |
| 제휴 배너 | 992 × 280 | 335 × 280 |

PC에서 사진 크롭과 카드 배치, 모바일에서 세로 히어로 크롭을 시각적으로 확인했습니다. 모바일의 기존 3열 특가·4열 평점 카드와 2열 여행지 배치는 좁고 일부 텍스트가 줄바꿈/넘침을 보이며 기존 가로 넘침 10px도 동일합니다. 이미지 삽입으로 새로 발생한 문제가 아니며, 요청된 레이아웃 유지 범위에 따라 수정하지 않았습니다.
